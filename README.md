# 斗魂演武场（douluo-combat）

SillyTavern 第三方扩展：给斗罗大陆角色卡用的斗魂战斗判定台。
武魂品质、魂环、魂技、魂骨、功法都能从酒馆文本里读，带有站位地图、行动条、破防与控制，
打完结算是可以直接写回聊天正文的。

## 安装

**TauriTavern / 桌面版**

扩展数据根目录（由 `%APPDATA%\com.tauritavern.client\tauritavern-runtime.json` 的 `data_root` 决定）：

```
<data_root>\extensions\third-party\douluo-combat\
```

把本目录整个拷进去，重启 app，在「扩展」抽屉里能看到「⚔ 斗魂演武场」。

**标准 SillyTavern**

```
SillyTavern/data/<你的用户名>/extensions/third-party/douluo-combat/
```

装完刷新页面，`扩展设置` 面板里会出现条目，点「打开斗魂面板」。

## 面板

是个浮窗。**拖标题栏能挪位置**，挪完记到设置里，下次打开还在原地。

```
│  │ ░░░░░░░░ 场外（走出去＝撤离）░░░░░░░░░░░░░░░░░░░░░░░ │  │
│  │ ┌─ 我方区 ──┐                  ┌─ 敌方区 ──┐          │  │
│  │ │    ●      │                  │      ▲     │          │  │
│  │ └───────────┘                  └────────────┘          │  │
│  └───────────────────────────────────────────────────────┘  │
│  ┌─ 我方 ────────────┐  ┌─ 敌方 ────────────┐              │
│  │ 单位卡（HP/韧）     │  │ 单位卡（HP/韧）     │              │
│  └────────────────────┘  └────────────────────┘              │
│  日志（战报）                                                │
│  行动条：技能按钮                                             │
│ [开始斗魂][写入正文][从卡导入][粘贴文本][认输][设置][探变量][重置队伍][自检] │
└─────────────────────────────────────────────────────────────┘
```

- **演武场**：占满上方整块，12 列 × 8 行，左边 4 列我方区、右边 4 列敌方区。
  开战前显示队伍站位预览；开战后点空格 = 移动（吃移速预算），点敌人 = 普通攻击，
  选了技能后点目标 = 施放。
- **单位卡**：在演武场**下方**，我方敌方左右两栏。显示等级 / 品质 / 类型 / 武魂 / 属性 /
  魂环档位，HP、魂力、韧性三条槽，攻防速、移速、命中闪避、暴击爆伤、穿透。
- **日志**：再往下，每条结算明细（含骰点），最多留 400 行。
- **工具栏**：
  - 开始斗魂 / 写入正文（把本轮日志推进聊天，会真实落盘）
  - 从卡导入：读角色卡文本 + MVU 变量，正则抽数据（默认加到我方）
  - 粘贴文本：弹窗，手动贴一段角色设定，可选加到我方还是敌方
  - 认输：我方全员退出演武场，直接判负
  - 设置：数据源开关、规则参数、显示项
  - 探变量：把 MVU 顶层结构打进日志
  - 重置队伍 / 自检

## 战斗规则

### 五维与派生

| 五维 | 影响 |
|---|---|
| 力量 str | 攻击 atk |
| 体质 vit | 生命上限、韧性上限、防御 |
| 敏捷 agi | 速度、移速、闪避 |
| 精神 spi | 精神攻击、暴击伤害、控制时长 |
| 魂力 sou | 魂力上限、技能威力、精神防御 |

武魂品质（`trash`/`normal`/`fine`/`epic`/`divine`）给五维乘 `0.72 / 1.0 / 1.14 / 1.32 / 1.55`。
魂师类型（强攻/敏攻/控制/防御/辅助/食物/双生）决定五维权重——敏攻偏敏捷、控制偏精神、防御偏体质。

### 按等级算属性（成长表）

编辑器五维下面有 **「按成长表重算」**，按《斗罗武魂完整数值体系》的公式填五维：

```
单维 = 等级 × (该品质总成长 / 5) × 系别向量[该项]
```

| 品质 | 五项单级成长总和 |
|---|---|
| 废武魂 | 2.0 |
| 普通武魂 | 5.0 |
| 良品武魂 | 6.5 |
| 极品武魂 | 9.0 |
| 神级武魂 | 13.0 |

| 系别 | 向量（力 / 体 / 敏 / 神 / 魂） |
|---|---|
| 强攻 | 1.6 / 1.0 / 0.7 / 0.7 / 1.0 |
| 防御 | 0.7 / 1.6 / 0.7 / 1.0 / 1.0 |
| 敏攻 | 1.0 / 0.7 / 1.6 / 0.7 / 1.0 |
| 控制 | 0.7 / 0.7 / 1.0 / 1.6 / 1.0 |
| 辅助 | 0.7 / 1.0 / 0.7 / 1.0 / 1.6 |

向量和恒为 5，所以**品质决定总量、系别决定形状**。

验算：神级控制 30 级 = `30 × (13/5) × [0.7,0.7,1.0,1.6,1.0]` = 54.6 / 54.6 / 78 / 124.8 / 78，和原文示例一致。

点完会在按钮右边显示一行「成品五维 STR … / VIT …」，值填进输入框后**还能手动改**。
注意它会**覆盖你手填或粘贴的数值**——手上已经有好数字就别点。

> 原文里废武魂的成长有两处写法（总成长 2.0 → 系数 0.4，第七节又写 0.3）。这里按 `2.0/5 = 0.4` 算，
> 因为它和「每级五维总和 = 总成长」这条主线自洽。你要用 0.3 就手改一下。

计算顺序固定：**收集修饰 → 五维（底子×权重×品质 + 固定加成）×（1+百分比）→ 派生 → 平面/百分比 → buff → 收敛**。
所以功法的 `spiPct: 12` 这种百分比加成对五维也生效。

### 属性与克制

内置 16 个属性，分三档：

| 档 | 属性 |
|---|---|
| 五行 | 金 木 水 火 土 |
| 四象 | 风 雷 光 暗 |
| 高阶 | 神圣 生命 毒 精神 时间 空间 毁灭 |

**判定规则**（`engine.elementRelation`）：

| 情况 | 伤害倍率 | 战斗日志 |
|---|---|---|
| 只有 A 克 B | ×1.5 | `克制 ×1.5` |
| 只有 B 克 A | ×0.5 | `被克 ×0.5` |
| A、B 互克 | ×1.5，**双方都吃** | `互克 ×1.5` |
| 无关 / 同属性 | ×1 | — |

互克是故意设计成不抵消的：光暗、时空、神圣毁灭、生命毒这几对互相克，
打起来就是「互相都疼」，而不是互相白给。

**默认克制表**：

| 属性 | 克 | 被谁克 |
|---|---|---|
| 金 | 木 | 火、雷 |
| 木 | 土 | 金 |
| 土 | 水、雷 | 木、风 |
| 水 | 火 | 土、雷 |
| 火 | 金 | 水 |
| 风 | 土、毒 | 雷 |
| 雷 | 水、金、风 | 土 |
| 光 | 暗 | 暗 |
| 暗 | 光、精神 | 光、神圣 |
| 神圣 | 暗、毁灭 | 毁灭、精神 |
| 毁灭 | 神圣、生命 | 神圣 |
| 生命 | 毒 | 毁灭、毒 |
| 毒 | 生命 | 风、生命 |
| 精神 | 神圣 | 暗 |
| 时间 | 空间 | 空间 |
| 空间 | 时间 | 时间 |

**自己改**：设置 → 「属性」「克制关系」两块。

- 输个名字点「+ 属性」，16 色调色板自动轮着分配
- 两个下拉选 A、B，点「+ 克制」加一条 `A 克 B`
- chip 上的 `×` 删属性，同时把它参与的所有克制对一起删掉
- 点「保存」才写进扩展设置；点「取消」整表回滚，随便试

改完立刻生效，下一场战斗就按新表算。属性名写进粘贴文本也能直接识别。

### 伤害

```
有效防御 = 防御 × (1 − 穿透/100)          穿透上限 80%
减伤率   = 有效防御 / (有效防御 + 120)
伤害     = 攻击 × 技能倍率 × (1 − 减伤率)
           × 暴击倍率      （d100 ≤ 暴击率时触发，倍率 = 爆伤/100）
           × 1.5           （目标处于破防）
           × 属性倍率      （克制 1.5 / 被克 0.5 / 互克 1.5）
           × 浮动          （0.90 + d10 × 0.02）
```

- 命中：`d100 ≤ 命中 − 目标闪避`，夹在 5%–98%
- 暴击：`d100 ≤ 暴击率`，上限 90%
- 属性克制见下面「属性与克制」一节

### 破防与控制

韧性上限 `= 50 + 体质×2.5 + 等级×1.5`，技能带 `poise` 削韧。
韧性归零 → 进入破防：受伤 ×1.5、跳过一次行动，之后按比例回复。

控制分两类，时长公式不同：

```
幻境类（精神压制）
  turns = round(基础回合 × clamp(施法者精神 / 受术者精神 × 0.85, 0.6, 2.4))

物理类（束缚/击晕）
  turns = round(基础回合 × (1 + 削韧量/韧性上限 × 3) × (1 − 剩余韧性比例 × 0.4))
```

两者最后都要乘 `(1 − 控制抗性/100)`，再夹在 1–4 回合。所以精神差越大幻境越久，
韧性被磨得越干净物理控制越久。

### 行动与位移

行动条（ATB）：每 tick 充能 `速度 × 攻速/100 × 0.08`，满 100 行动，12 tick 算一回合。
速度 100 的单位大约一回合动一次，速度 200 的动两次。

距离用切比雪夫（八方向，斜走算 1 格）。移速 `= 2 + 敏捷/10`，每回合有移动预算，
超出预算的位移会被拒绝。技能可以带 `push`/`pull`/`dash` 做击退、拉近、突进。

### 逃跑与认输

战斗中演武场外围会多出一圈**虚线格**（场外）。两个口子退出：

**走出去**——轮到自己时点外圈格，走进去就算撤出演武场：

- 该单位 `alive = false`、标记 `fled`，HP 清零，坐标移到 `-1,-1`
- 日志写「XX 从 a,b 撤出演武场，逃跑成功」
- 距离照样吃移速预算，够不到就提示「够不到场外」
- 一方**全员撤离或全灭**，该方判负，战斗结束

**认输**——工具栏点「认输」，确认框过一下，我方全员退出，直接判负。

不管哪种，战报都会分开写：

| 情况 | 战报落款 |
|---|---|
| 打死的 | `我方全灭` / `我方胜利` / `同归于尽` |
| 有人走出去 | `我方溃逃，判负` / `我方胜利（敌方溃逃）` / `双方俱退，判平` |

`checkEnd` 是幂等的，逃跑和认输都只写一条结束日志，不会重复。

### 护盾与穿透

护盾先吃伤害，有持续时间。穿透按百分比削减目标防御，对高防单位收益最大
（打 153 防的目标，23% 穿透大约多 15% 伤害）。

## 从文本导入

点「从卡导入」，默认只读两个稳定来源：

1. **角色卡文本** —— `description` / `personality` / `scenario` / `system_prompt`
2. **MVU 变量** —— 走 `TavernHelper.getVariables({ type: 'chat' })`

世界书和聊天记录噪音大，**默认关闭**，在「设置」里能逐项打开。

MVU 经常是几百项（提示词开关、别的扩展状态、剧情选项），直接丢给正则会误判
（比如把「回复长度 2000」当成等级）。所以先过一遍字段白名单，只留 key 里带
`魂力/魂环/武魂/魂技/魂骨/功法/等级/境界/修为/力量/体质/敏捷/精神/攻击/防御/速度/韧性…` 的项，
再把剩下的交给正则。日志会写清楚「命中 N/M 项」，命中 0 就说明这张卡里没有战斗数据。

**「探变量」按钮**会把 MVU 顶层分组打出来（`组名：对象，N 项`），方便你确认角色数据
埋在哪一层、字段到底叫什么名字。

然后按正则抽这些字段：

| 字段 | 认得的写法 |
|---|---|
| 名字 | `姓名：` / `# 标题` / 解析不到时用当前角色卡名 |
| 等级 | `魂力等级：52级` / `52级魂师` / `Lv.52` |
| 武魂 | `武魂：蓝银皇`（名字后的「（极品）」会剥掉，但品质从它读） |
| 品质 | `极品`/`上品`/`良品`/`普通`/`废武魂`，或 `S/A/B/C` |
| 类型 | `控制系`/`强攻系`/… |
| 属性 | `属性：木` 或从武魂名猜（蓝银→木、冰→水、锤→金） |
| 五维 | `力量：68 体质：75 …` |
| 魂环 | `黄黄紫紫黑` 配色串 / `第3魂环：千年` / `3000年魂环` |
| 魂技 | `第一魂技：缠绕（束缚）` |
| 魂骨 | `万年右臂魂骨` / `右臂万年魂骨` 两种语序都认 |
| 功法 | 匹配内置功法名（凝神诀、疾风诀…） |
| 装备 | 匹配内置装备名 |

**魂技的机制参数靠关键词猜**：名字里带「缠/缚/锁/困」→ 物理控制，带「幻/梦/魅/瞳」→ 幻境控制，
带「炎/焰/焚/爆」→ 精神多段，带「盾/甲/护」→ 护盾，带「愈/疗/春/润」→ 治疗，
带「扫/荡/旋/乱」→ 物理群攻，其余按单体物理。

猜完会打开编辑器，让你逐项改完再保存。解析结果会写日志，缺哪些字段也有提示。
这套是正则，不是语义理解——卡写得规范就抽得准，写得随意就得手改。

### 一行一单位的写法（推荐）

如果文本是「第一行一个人、后面几行是技」这种结构，会走专用解析，**比正则猜得准得多**：

```
唐三:Lv.29,控制系,蓝银草,废武魂,str=7.88,vit=7.88,agi=11.25,spi=18.00,sou=11.25,功法=玄天功(str=2,vit=2,agi=3,spi=8,sou=5,atkPct=5)
魂技1:缠绕,木,控制,倍率0.3,耗魂力6,冷却2,削韧15,穿透0,射程3,范围单体,控制=束缚,位移=原地,说明=蓝银草远程捆缚，最远3格
魂技2:寄生,木,减益,倍率0.4,耗魂力7,冷却3,削韧10,穿透0,射程3,范围单体,控制=不控制,位移=原地,说明=种子埋入目标体内，3格内投放
玄技:紫极魔瞳,精神,探测/精神伤害,倍率0.7,耗魂力8,冷却3,削韧18,穿透0,射程4,范围3×3群体,控制=致盲,位移=原地,说明=紫极神光冲击，4格内3×3范围
```

**头部行**：`名字:Lv.等级,系别,武魂,品质,str=…,…,功法=名字(加成)`

- `Lv.29` 或 `等级29` 都行
- `控制系` / `控制` 都认
- `废武魂` / `废` / `普通` / `良品` / `极品` / `神级`
- 五维写 `str=7.88`
- `功法=玄天功(str=2,vit=2,atkPct=5)`，括号里的加成变成这个人的功法

**技能行**：`魂技N:名字,属性,类别,键=值,…`

前缀 `魂技` / `玄技` / `秘技` / `绝技` / `功法` / `魂骨` / `装备` 都认。

- **属性**：内置 16 个都能直接认（金木水火土风雷光暗神圣生命毒精神时间空间毁灭），你在设置里加的自定义属性名也能写
- **类别**：控制 / 减益 / 增益 / 治疗 / 护盾 / 探测 / 精神伤害 / 物理
- **键值**：`倍率0.3`（不带等号也认）、`耗魂力6`、`冷却2`、`削韧15`、`穿透0`、`射程3`
- **范围**：`单体` / `自身` / `3×3群体` / `群体`
- **控制**：`束缚` / `致盲` / `眩晕` / `沉默` / `减速` / `冻结` / `不控制`
- **位移**：`原地` / `机动N格` / `突进` / `击退`
- **说明**：`说明=…` 里可以带全角逗号 `，`，不会被切断

只按**半角逗号** `,` 切字段，所以说明里中文逗号随便用。

没写五维按成长表补；没写魂环按等级推（一环百年、二环千年、三环三千年、四到八环万年、九环十万年）。
魂环上会自动挂上前几个技能，方便看。

实测：上面这段唐三解析出来是 `废武魂 · 控制系 · 木属性 · Lv.29`，
四个技能分别识别成 `控制(root) / 减益 / 精神群体(致盲) / 增益(自身, 机动2格)`，
功法 `玄天功` 带 `str+2 vit+2 agi+3 spi+8 sou+5 atkPct+5`。

「粘贴文本」是个弹窗，把角色卡里和战斗有关的一段贴进去，效果跟「从卡导入」一样，
适合卡里没有结构化字段、但你自己手上有设定的情况。

## 魂技 / 魂骨 / 功法 / 装备：每人一份

这四类东西**都是每个单位自己的一份**，不是全队共享的池子。改甲单位的魂技，乙单位一毛钱不受影响。

编辑器里每类都是「列表 + 加 + 删 + 改」：

- **改** — 打开编辑弹窗，所有字段随便调
- **×** — 从这个人身上拿掉（不删模板）
- **+ 自定义** — 从零写一个
- **+ 从模板添加…** — 从预设库里挑一个，**复制一份副本**加进来；之后改这份副本不会动到模板

列表里带 **「·私有」** 标记的，就是这个人自己的副本，可以随便改。没有标记的，说明还在引用模板库的原件——点一下「改」就会自动转成副本。

> 点「重置队伍」会把人重新生成为预设状态，私有改动全部丢掉，回到默认值。
> 这不是 bug：它证明改动确实只留在这个人身上，没渗进模板。

### 魂技

字段全部可填：

| 字段 | 影响 |
|---|---|
| 名字 | 战报里显示的名字 |
| 属性 | 参与属性克制（见「属性与克制」） |
| 类别 | 物理 / 精神 / 治疗 / 增益 / 减益 / 护盾 / 控制，决定走哪条结算路径 |
| 倍率 | 攻击力的倍数，`1.0` ≈ 一次普攻 |
| 消耗魂力 | 放一次扣多少蓝 |
| 冷却 | 放完要隔几回合才能再放 |
| 射程 | 切比雪夫距离下的格数 |
| 削韧 | 打掉对方多少韧性 |
| 穿透 % | 无视多少防御（受设置里的上限封顶） |
| 范围 | 单体 / 敌方全体 / 我方全体 |
| 控制 | 物理束缚（对抗韧性）/ 幻境（对抗精神力差） |
| 位移 | 原地 / 突进到目标身边 / 击退目标 |
| 说明 | 出现在战报里的描述文字 |

魂环年限那一栏只影响属性加成（年限越长加得越多），不再往技能栏里塞技能——技能统一在「魂技」列表里管。老存档里挂在魂环上的技能，打开编辑器时会自动并到列表里，能看见也能改。

### 魂骨 / 功法 / 装备

- **魂骨**：名字、部位（头/躯干/左右臂/左右腿）、年限。年限决定档位——百年≈1000、千年≈3000、万年≈20000、十万年≈100000。
- **功法**：名字、加成、说明。
- **装备**：名字、部位（武器/护甲/饰品自由填）、加成。

后三者的「加成」用一行文本写，格式 `键=数值`，逗号分隔：

```
atkPct=8, critDmgPct=6, str=5, moveFlat=1
```

规则：
- 五维直接写 `str` `vit` `agi` `spi` `sou`（对应力/体/敏/神/魂）
- 百分比加 `Pct` 后缀：`atkPct` `defPct` `spdPct` `hpPct` `critPct` `critDmgPct` `penetrationPct` `ctrlPct` `poisePct` `healPct` `shieldPct` `ctrlResistPct` `poiseDmgPct`
- 固定值加 `Flat` 后缀：`moveFlat` `atkSpdFlat` `penetrationFlat`
- 写错键名不报错，只是不生效

### 实测记录

改我方敏攻系魂师的「裂石斩」倍率 `1` → `1.8`：列表立刻显示 `土·5魂力·1.8倍·射程1 ·私有`。
点「重置队伍」后重开编辑器，回到 `土·5魂力·1倍·射程1`，私有标记消失——改动只留在这个人身上，模板没被污染。

## 设置

工具栏「设置」里能改：

| 类别 | 项 | 说明 |
|---|---|---|
| 导入数据源 | 角色卡文本 / 内嵌世界书 / MVU 变量 / 聊天记录 | 默认只开「角色卡文本」和「MVU」 |
| 战斗规则 | 防御常数 K / 穿透上限 / 控制上限回合 / 行动条系数 | 改完立刻作用于引擎 |
| 显示与写入 | 日志显示骰点 / 结束自动写入 | |

参数含义：

- **防御常数 K**：减伤率 = 有效防御 / (有效防御 + K)。K 越大，同样的防御减伤越少。
- **穿透上限**：百分比穿透封顶值。
- **控制上限回合**：任何控制最长持续几回合。
- **行动条系数**：每 tick 充能 `速度 × 攻速/100 × 该值`，满 100 行动。
  `0.08` ≈ 速度 100 的单位一回合动一次；调到 `0.16` 就是一回合两次。

## 常见问题

**面板点不动 / 按钮在面板外面**
面板高度是 `auto` + `max-height`，屏幕小于 800px 高时会被裁。缩放一下浏览器或换个窗口尺寸。

**导入出来是空的**
当前卡没有描述文本。换一张写了武魂/魂环的卡，或者用「粘贴文本」手动贴。

**开战双方够不着**
默认站位是我方 x=3~4、敌方 x=8~9，中间隔 4 格。用射程 5 的技能，或者先走两回合。
编辑单位里能直接改站位。

**改了数据要重启吗**
扩展是 ES module，改完文件刷新页面即可；TauriTavern 里需要重启 app。

`getContext` / `chat` 条数 / `addOneMessage` / `saveChat` / `characters` 数量 /
